# Code map — elkis.dev portfolio

Living index of WHERE things live. Verify against code before acting on it.
Astro 6 static site, bilingual via `data-en`/`data-es` spans + `data-lang` on `<html>` (global rules in `src/styles/global.css`). Single-URL bilingual pages — only `/` has a separate `/es` route with hreflang alternates.

| Subsystem           | Path                                                                                                               | Responsibility                                                                                                                      |
| ------------------- | ------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| Layout shell        | `src/layouts/BaseLayout.astro`                                                                                     | Head/SEO (canonical, hreflang for home pair, OG), Nav + Footer, lang auto-detect                                                    |
| Navigation          | `src/components/Nav.astro`                                                                                         | Sticky nav, active state by pathname, lang toggle, mobile drawer                                                                    |
| Home sections       | `src/components/home/*.astro`                                                                                      | Hero, Work, Methodology, Timeline, CTA (mailto-based contact form)                                                                  |
| Pages               | `src/pages/{index,now,uses,view-source,404}.astro`, `about/`, `blog/`, `work/`, `es/index.astro`, `services.astro` | Route per file; `work/[slug]` + `blog/[slug]` render content collections                                                            |
| Services page       | `src/pages/services.astro`                                                                                         | Commercial page: services w/ case-study proof links, real testimonial, FAQ + JSON-LD (ProfessionalService, FAQPage, BreadcrumbList) |
| Content collections | `src/content.config.ts` + `src/content/{projects,blog}/`                                                           | Zod schemas; projects support optional `demo` (live / video / gallery)                                                              |
| Case study demos    | `src/components/ProjectDemo.astro`                                                                                 | Renders `demo` frontmatter block on `work/[slug]`; assets live in `public/demos/`                                                   |
| Interactive demos   | `src/components/demos/LeadScoringDemo.astro` + `src/scripts/lead-demo-scoring.ts`                                  | In-browser simulation of the lead scoring pipeline; pure logic is unit-tested                                                       |
| Tests               | `tests/*.test.ts`                                                                                                  | Vitest (`pnpm test`)                                                                                                                |
| Styles              | `src/styles/global.css`                                                                                            | Design tokens (dark premium, teal accent), i18n display rules, container                                                            |
| Telemetry           | `.spec-flow/events.jsonl`                                                                                          | spec-flow change labels, committed with each change                                                                                 |
